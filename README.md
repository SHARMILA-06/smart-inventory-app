# 🚀 Smart Inventory & Analytics App

A lightweight and robust backend web application built with **FastAPI** and **SQLite**, designed to manage smart inventory systems efficiently. Built as an industrial-standard project profile enhancer for backend development and database management.

## 🛠️ Tech Stack
* **Backend:** Python, FastAPI, Uvicorn
* **Database:** SQLite, SQLAlchemy (ORM)
* **Version Control:** Git & GitHub
